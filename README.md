# Athlete Planner

A season planner for athletes: one calendar for games, team practice, skills, S&C and recovery, with load tracking and red flags for overuse.

- **Language:** Lithuanian (English available on the welcome screen)
- **Runs on:** iPhone, Android and computers. It's a web app, opened in the browser and added to the Home Screen.
- **Hosting:** GitHub Pages

## Status
Early development. First test version in progress.

## How it's built
- `index.html`: the app itself, a single page with HTML, CSS and JavaScript.
- Data is saved on the user's own phone (browser storage) in the test version.
- Later: game schedules collected automatically (GitHub Actions), Firebase for sync and reminders.
